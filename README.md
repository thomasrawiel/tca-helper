# TCA Helper

TCA helper functions intended to simplify the registration of custom Content Element types, Page types & more.

> [!NOTE]    
> The methods described in this project reflect the author's opinion and preferred way of working.  
> All functionality provided here can also be achieved using TYPO3 core mechanics.

## TYPO3 Core References

If you prefer the official TYPO3 way, refer to:

- [Create a custom content element type](https://docs.typo3.org/permalink/t3coreapi:adding-your-own-content-elements)
- [Create new Page Type](https://docs.typo3.org/permalink/t3coreapi:page-types-example)
